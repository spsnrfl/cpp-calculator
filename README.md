# C++ Calculator

Консольный калькулятор на C++ с поддержкой динамических DLL-плагинов.

## Возможности

- Арифметические операции: `+`, `-`, `*`, `/`.
- Поддержка скобок.
- Возведение в степень через плагин `power`.
- Вычисление синуса через плагин `sin`.
- Вычисление натурального логарифма через плагин `ln`.
- Автоматическое обнаружение DLL в папке `plugins`.
- Обработка ошибок вычислений и некорректных плагинов.

## Пример

```text
2^4 + sin(90) + ln(1)
= 17
